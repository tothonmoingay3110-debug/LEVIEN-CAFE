LEVIEN CAFE — V2 MODULE 4 ORDER DISPLAY UPDATE

1. Keep your existing .env.local file. It is not included in this package.
2. Copy this package over the current LEVIEN-CAFE project.
3. From the project directory run:

   npm.cmd install
   npm.cmd run build
   npm.cmd run dev

4. No new Supabase SQL migration is required.
5. Open Admin -> Orders -> Open TV Display, or visit:

   http://localhost:3000/order-display

6. Test an order through New/Preparing, Ready, Completed and Cancelled.
7. After deploying, run:

   npm.cmd run smoke:production -- https://your-production-domain.com

Required server environment variables remain unchanged. In particular,
SUPABASE_SERVICE_ROLE_KEY must be configured server-side for the public board
API to read its privacy-limited order status data.
