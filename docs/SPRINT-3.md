# Sprint 3 — LEVIEN Admin Platform

## Included
- Admin login demo: `admin` / `123`
- Responsive LEVIEN-branded sidebar and dashboard
- Product CRUD with image preview, toppings and badges
- Category, topping, combo and promotion management
- Online order queue and status updates
- Logo, announcement, Our Story, contact and map settings
- Browser localStorage persistence for hands-on testing

## Route
- `http://localhost:3000/admin`

## Important
Sprint 3 is a front-end administration prototype. Data and uploaded images are stored in the current browser only. Supabase authentication, database persistence, storage and synchronization are the next integration step.
