# V3.1 — Report Center

## Access

Report Center is available to Owner and Manager under:

`Admin → Planning & Reports → Report Center`

Supervisor and Staff cannot access the page or its API. The server checks the
dedicated `view_sales_reports` permission for every report request.

## Reports

- **Sales:** completed-order sales grouped by day.
- **Orders:** order number, date, customer, fulfillment type, status and
  completed-order subtotal after loyalty discount.
- **Customers:** completed orders, spend and most recent order.
- **Products:** quantity sold, quantity included in combos, order count and
  standalone product sales.
- **Promotions:** promotion content, slide position and publishing status.
- **Combos:** quantity, order count and sales.

The report range supports up to 366 days. Display tables show at most 200 rows
to keep the Admin UI responsive; exports include every row returned for the
selected range.

## Export

Each selected report can be downloaded as:

- UTF-8 CSV for data tools and spreadsheets.
- Excel-compatible `.xls` for direct opening in Microsoft Excel.

No customer passwords, staff compensation, tracking tokens or payment secrets
are included. The first version intentionally does not show tax or advanced
accounting details.

## Deployment

No Supabase migration or new environment variable is required.

1. Run `npm.cmd install`.
2. Run `npx.cmd tsc --noEmit`.
3. Run `npm.cmd run build -- --webpack`.
4. Sign in as Owner or Manager and test every report tab.
5. Export one CSV and one Excel file and confirm both open correctly.
