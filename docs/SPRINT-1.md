## Apply to an existing local project
Stop the development server with `Ctrl + C`, then replace these folders/files from the update package:

- `app/page.tsx`
- `app/globals.css`
- `components/`

Start the server again:

```powershell
npm.cmd run dev
```

No new npm package is required for this UI update.
