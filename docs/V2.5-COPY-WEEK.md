# V2.5 — Copy weekly schedule

V2.5 lets Owner and Manager reuse a published seven-day schedule in a future
week. It speeds up recurring scheduling without deleting or overwriting any
existing shift.

## Included

- Management-only **Copy week** action inside Schedule.
- Source and target week-start date selection.
- Copies date, start/end time, employee, station, and manager note.
- Preserves all source shifts.
- Preserves all existing target shifts.
- Skips inactive employee accounts.
- Skips Owner assignments when the actor is a Manager.
- Skips shifts that overlap approved V2.4 time off.
- Skips shifts that overlap an existing target assignment for that employee.
- Displays source, created, conflict, time-off, inactive, and permission counts.
- Opens the target week after completion.

## Permissions

| Action | Owner | Manager | Supervisor | Staff |
| --- | --- | --- | --- | --- |
| Copy team week | Yes | Yes | No | No |
| Copy Owner shifts | Yes | No | No | No |
| See copy result | Yes | Yes | No | No |

The API independently checks `manage_schedule`; hiding the browser button is not
the only authorization control.

## How to use

1. Sign in to `/admin` as Owner or Manager.
2. Open **Schedule**.
3. Choose **Copy week**.
4. Select the first day of the seven-day source range.
5. Select a future target start date.
6. Choose **Copy schedule**.
7. Review the created and skipped counts.
8. Choose **View target week** to inspect the published result.

For the clearest Monday–Sunday calendar, choose Monday for both source and target
dates. The server still copies exactly seven consecutive dates when another
start day is selected.

## Conflict behavior

A source shift is skipped when:

- Its employee account is inactive.
- A Manager attempts to copy an Owner assignment.
- Approved time off covers the target date.
- The employee already has an overlapping target shift.

One skipped assignment does not stop other valid assignments from being copied.
The result dialog explains each skip category.

## Verification checklist

- Staff and Supervisor cannot see or call Copy week.
- Copying a populated source week creates matching target shifts.
- Existing target shifts remain unchanged.
- Repeating the same copy skips duplicates as conflicts.
- Approved time-off dates are skipped.
- Locked employee assignments are skipped.
- Manager cannot copy Owner shifts; Owner can.
- Schedule and Labor Planning reflect the new target shifts.

## Database impact

V2.5 writes normal rows to the existing `staff_shifts` table. It does not add a
table, column, enum, or migration.
